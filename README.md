# MIMI

**Voir le site : [https://youss-dev-mimi.netlify.app](https://youss-dev-mimi.netlify.app)**

Site vitrine d'une boutique de cookies et smoothies (projet de démonstration, marque fictive).

Réalisé par **Youssouf**, développeur web freelance, comme pièce de portfolio.

## Points clés

- Hero plein écran avec animation au scroll (GSAP ScrollTrigger) : épinglage, réduction à coins arrondis, fondu
- Sélecteur de langue FR / EN / ES
- Carrousel photo et transitions de sections en vagues SVG
- Carte à onglets (Cookies / Smoothies / À emporter)
- Grille Instagram et carte de localisation stylisée (OpenStreetMap)
- Responsive (mobile, tablette, desktop), sans framework ni étape de build

## Stack

HTML, CSS, JavaScript vanilla, GSAP. Site statique, déployé sur Netlify.

## Lancer en local

Ouvrir `index.html` dans un navigateur.
